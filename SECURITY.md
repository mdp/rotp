# Security Policy

## Supported Versions

Security fixes are provided for the latest major version only. The current supported line is 6.x.

| Version | Supported          |
| ------- | ------------------ |
| 6.x     | :white_check_mark: |
| < 6.0   | :x:                |

## Reporting a Vulnerability

Please report security vulnerabilities privately. Do not open a public GitHub issue.

Use GitHub private vulnerability reporting:

1. Open the [Security tab](https://github.com/mdp/rotp/security) for this repository.
2. Choose **Report a vulnerability**.
3. Include the affected version, a description of the impact, and steps to reproduce if you have them.

You should receive an acknowledgment within a few days. If the report is accepted, a fix will be prepared for the supported release line.
